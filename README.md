# Scalable Real-time Detection of AI-Generated Arabic Text

A distributed data pipeline for detecting AI-generated Arabic text using Big Data tools.

## Dataset
[KFUPM-JRCAI/arabic-generated-abstracts](https://huggingface.co/datasets/KFUPM-JRCAI/arabic-generated-abstracts)

## Tech Stack
- **Storage**: HDFS, Parquet
- **Processing**: Apache Spark (PySpark)
- **NLP**: PyArabic, CAMeL Tools, AraBERT
- **Streaming**: Apache Kafka + Spark Structured Streaming
- **ML**: Spark MLlib
